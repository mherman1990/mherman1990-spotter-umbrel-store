# Herman Apps — Umbrel community app store

Add this store on your Umbrel: **App Store → ⋯ → Community App Stores**, then paste
this repository's URL.

| App                       | Description                                    |
| ------------------------- | ---------------------------------------------- |
| [Spotter](herman-spotter) | Self-hosted strength-training log and AI coach |

This directory lives in the [`spotter`](https://github.com/mherman1990/spotter) repo
under `umbrel-store/`. The release workflow syncs it to the store repo and pins
each release's image digest. Edit it there, not in the store repo.
